SUNDAYNESE - Satirical 1-Day Sundanese Life Simulation (Greenfoot Java)
------------------------------------------------------------------------

PROJECT TITLE: Sundaynese
PURPOSE OF PROJECT: 3rd-Semester OOP Final Project (UAS)
VERSION or DATE: 1.0.0 (2026-11-26)
HOW TO START THIS PROJECT:
  1. Open this folder in Greenfoot (project.greenfoot).
  2. Click "Compile" if needed, then click "Run" on TitleWorld.
  3. Use WASD / Arrow keys to walk, and E / SPACE (or mouse clicks on Phone)
     to interact and play each mini-game from wake-up until bedtime.
